## 2. Comprehensive Security Review (All New Execution Paths)

| Execution Path | Security Controls Verified |
|---|---|
| **Fast-Path (`fastpath.py`)** | Executes strictly via `skills.run()`. Respects Lockdown, `skill_permissions` (`off`/`ask`), confirmation previews, and `secure.audit("fast_path")`. Disabled in `talk` mode. |
| **Background Tasks (`bgtasks.py`)** | Refuses T2/T3 risky tools at creation and execution (`ALLOWED_BG_TIERS = {"T0", "T1"}`). Parallel runner permits T0 only. Blocked during Lockdown. Crash recovery marks tasks `recovered` rather than silently re-running. |
| **Macros (`macros.py`)** | Replays strictly via `skills.run()`. Halts immediately if any step triggers confirmation preview or Lockdown is active. |
| **Browser Automation (`browser_auto.py`)** | Route-level interceptor (`context.route("**/*")`) enforces public HTTPS and blocks RFC1918/loopback/link-local SSRF (`169.254.169.254` verified aborted in live Chromium) across navigations, redirects, and subresources. |
| **Mobile Companion (`companion.py`)** | Disabled by default (`remote_companion_enabled = False`). Never binds `0.0.0.0`. Single-use 120s pairing codes, failed-attempt rate limit (5/300s), SHA-256 hashed tokens with TTL expiration, instant revocation, Lockdown override, and strict T0 read-only command allowlist. |
| **External Connectors & OAuth (`service_adapters.py`, `net.py`)** | Fail-closed `net.py` allowlist only opens connector hosts when `allow_internet_tools=True` AND DPAPI secret exists. Tokens stored in Windows DPAPI. Home Assistant writes require explicit `connector_write_permissions`. |
| **Voice & Standing Instructions (`voice_profile.py`)** | `can_authorize_sensitive_action()` unconditionally returns `False`. No raw audio persisted. Standing instructions screened by `secure.looks_like_injection()`. |
| **XLSX / Documents / Finance (`pro_workspace.py`, `domains.py`)** | Pure-stdlib XLSX parser enforces 5 MB size cap, ZIP-bomb uncompressed cap, and rejects NUL bytes, `<!DOCTYPE`, and `<!ENTITY`. Finance analytics strictly gated by `domains.check_domain_access("finance", write=False)`. |
| **Native Shell & Hotkeys (`native_shell.py`, `hotkeys.py`, `rust/jarvis-core`)** | Native shell refuses non-`127.0.0.1` URLs. Emergency Kill Switch (`Ctrl+Alt+Backspace`) audited. Rust `jarvis-core` blocks `.ssh`/`.aws`/`secrets.bin` and privilege elevation (`sudo`/`runas`/`-enc`). |
