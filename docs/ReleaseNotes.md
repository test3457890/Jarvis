Jarvis 1.2.0 replaces Jarvis.bat with a Start menu shortcut that runs Python directly and adds a first-run setup wizard with model sizes, free space, a storage budget and resumable downloads. It adds previewed file tasks in folders you select, with a journal, resume, undo and recoverable deletion. Coding uses focused multi-file patches with syntax checks, all-or-nothing apply and approved project test runs. TUKI has its own voice, broader technical routing and states its confidence and what it checked. Three new themes were added.

The release is not code-signed. Verify the ZIP with SHA256SUMS.txt. Close Jarvis before running upgrade.ps1. The updater replaces shipped program files only and keeps your settings, data and the old Jarvis.bat. Run install.ps1 afterwards to refresh packages and create the shortcut.

Automated tests ran on Linux, with Windows tests in CI. Performance on an 8 GB Windows PC has not been measured. See docs/Benchmarks.md and CHANGELOG.md.
