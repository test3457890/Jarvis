Jarvis 1.3.0 restores the "Are you sure?" prompts for deleting a remembered fact, restoring a backup, clearing history and downloading above the storage budget, which since 1.1 had gone ahead without asking. Every HUD control is now exercised by an automated audit that checks its real result. Coding adds related files as read-only context, sizes requests to the performance profile (the 8 GB profile no longer overflows its model context), adds approved builds, feeds failure output back, and keeps undo across restarts. New: a Screen panel that captures one window you choose and sends it to the local vision model only when you ask; approved app actions with Stop; optional local OCR with Tesseract; and extensions that stay off until you approve the permissions they declare. "Jarvis, stop" cancels a reply that is still being prepared.

The release is not code-signed. Verify the ZIP with SHA256SUMS.txt. Close Jarvis before running upgrade.ps1. The updater replaces shipped program files only and keeps your settings and data. Run install.ps1 afterwards to refresh packages.

Automated tests ran on Linux and in Windows CI with stubbed models. Real-model quality and speed on an 8 GB Windows PC, the microphone, screen capture of real windows, app actions on Windows and OCR on Windows still need testing on the target PC. Spoken interruption while Jarvis is speaking is not included. See CHANGELOG.md and docs/Capabilities.md.
